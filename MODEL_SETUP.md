# Настройка Gemini API · v11.6.0

## 1. Получить ключ

Откройте https://aistudio.google.com/api-keys и создайте ключ Gemini API.

## 2. Сохранить ключ в приложении

Запустите проект, откройте «Помощник · Gemini», вставьте ключ и нажмите «Сохранить ключ». Секрет сохраняется только сервером в `~/.kvartal/gemini_api_key.txt`, вне папки сайта. Ответы API никогда не возвращают ключ в браузер.

Альтернатива: задать переменную окружения `GEMINI_API_KEY` перед запуском сервера. В этом случае ключ из файла настроек не используется.

## 3. Проверить

В окне помощника подтвердите согласие на облачную обработку и нажмите «Проверить ключ». Выполняется один короткий запрос к `gemini-3.1-flash-lite`.

## 4. Нагрузка и приватность

- Не загружаются локальные модели, ONNX, WebGPU или AI Worker.
- Компьютер пользователя не выполняет генерацию текста.
- Запрос к Google выполняется только по нажатию кнопки.
- На Free Tier Google может использовать отправленный контент для улучшения продуктов. Не отправляйте конфиденциальные или специальные категории персональных данных.
- Проект старается скрывать email, телефоны и явные фразы «меня зовут», но автоматическая очистка не гарантирует полное обезличивание. Проверяйте текст обращения.
- При ошибке квоты 429 приложение использует встроенный шаблон; на другую/платную модель не переключается.
- API-ключ не включается в архив и исключён через `.gitignore`.
