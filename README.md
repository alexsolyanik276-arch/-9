# Квартал Менеджмент — диспетчерская

## Версия 11.6.0 · Google Gemini API (cloud)

В этой версии генеративный ИИ работает на серверах Google через Gemini API. На компьютере пользователя **не запускаются модели, WebGPU, ONNX, Transformers.js, AI Worker или локальный инференс**. Локальный Python-сервер обслуживает интерфейс, Excel и проксирует запросы к Google только по явному действию пользователя.

### Быстрый запуск

1. Распакуйте архив целиком.
2. Нужен Python 3.10+ для веб-сервера проекта.
3. В Windows запустите `run_windows.bat`; в macOS/Linux — `./run_mac_linux.sh`.
4. Откройте `http://127.0.0.1:8765`.
5. Нажмите «Помощник · Gemini» и настройте API-ключ.

### Настройка бесплатного Gemini API

1. Откройте [Google AI Studio — API keys](https://aistudio.google.com/api-keys).
2. Создайте API-ключ для Gemini API.
3. Вставьте его в окно «Помощник · Gemini» и нажмите «Сохранить ключ».
4. Подтвердите согласие на облачную обработку данных (прочитайте предупреждение о конфиденциальности).
5. Нажмите «Проверить ключ» — проект сделает один короткий тестовый запрос.

Используется только `gemini-3.1-flash-lite`. В актуальной таблице Google AI Studio для этой модели указана бесплатная стоимость входных и выходных текстовых токенов на Free Tier. Квоты зависят от проекта Google и могут меняться. При ответе API 429 проект не переключается на платную модель: он использует встроенный шаблон.

**Важно о бесплатном тарифе:** Google указывает, что данные, отправленные через Free Tier, могут использоваться для улучшения продуктов. Не подключайте к такому API конфиденциальные обращения и специальные категории персональных данных. Для уменьшения риска проект не передаёт имя заявителя и контакты, а сервер дополнительно скрывает типичные email/телефоны и явные фразы с именами. Автоматическая очистка не гарантирует полное обезличивание — оператор должен проверить текст. Для чувствительных данных используйте тариф и условия обработки, подходящие вашей организации.

Ключ хранится в личной папке пользователя сервера (`~/.kvartal/gemini_api_key.txt`), вне корня сайта и недоступен как статический файл. В браузер ключ не возвращается. Можно удалить ключ кнопкой «Удалить ключ». Если ключ хранится в переменной окружения `GEMINI_API_KEY`, приложение использует её вместо файла.

### Функции ИИ

- Анализ обращения: краткая суть, важные факты, недостающие сведения и уточняющий вопрос.
- Ответ арендатору: черновик в деловом стиле на основе карточки обращения и статуса связанной работы.
- Сводка по работе: задача, место, статус, назначение исполнителя, число обращений и вопросы.

ИИ только предлагает тексты. Статусы, связи обращений, исполнителей и значения Excel меняет только обычная логика интерфейса после действий диспетчера. Черновики и сводки нужно проверять перед использованием.

### Нагрузка на компьютер

На клиентском компьютере Gemini не запускается и модельные файлы не скачиваются. Во время работы ИИ браузер отправляет небольшой текстовый запрос локальному серверу; сервер обращается к Google. Запросы выполняются только после нажатия кнопки, без фоновых задач. На стороне клиента нет GPU/CPU-инференса.

### Данные Excel

- Рабочая книга: `data/active.xlsx`.
- Служебное состояние и черновики: `data/app_state.json`.
- При переносе проекта сохраните `data/active.xlsx` и `data/app_state.json`.
- Новый ключ Gemini не передавайте вместе с архивом и не коммитьте в Git.

### Docker

Docker Compose запускает только веб-сервер проекта. Убедитесь, что `data/` смонтирована как постоянный volume. Для ключа можно задать `GEMINI_API_KEY` в окружении контейнера либо настроить его через интерфейс (ключ сохранится в named volume `kvartal_secrets`, смонтированном в `/root/.kvartal`).

```bash
docker compose up -d --build
```

Не публикуйте сервер в открытый интернет без HTTPS, авторизации и резервного копирования. Встроенные механизмы авторизации проекта не предназначены для публичного хостинга.
